# 21世纪内阁 · Windows 发行版

普通用户只需要运行 `CenturyCabinet-Setup-<版本>.exe`。安装时可选择程序目录；完成后可从桌面或开始菜单直接打开“21世纪内阁”。

## 发行版特点

- 自带私有 Python 运行时和全部程序依赖。
- 不安装 Python、Node.js 或 npm，不修改系统 `PATH`。
- 安装、首次密码设置、启动和卸载均为图形界面，不显示 CMD、PowerShell 或命令行窗口。
- 主程序、公众号采集器由同一个“21世纪内阁”入口在后台启动。
- 程序默认安装在 `%LOCALAPPDATA%\Programs\CenturyCabinet`，也可选择其他磁盘上的目录。
- 个人数据保存在 `%LOCALAPPDATA%\CenturyCabinet\Data`，与程序分离。

## 卸载

可以使用下列任一入口：

1. Windows“设置 → 应用 → 已安装的应用 → 21世纪内阁 → 卸载”；
2. 开始菜单中的“卸载21世纪内阁”；
3. 程序安装目录中的 `Uninstall-CenturyCabinet.exe`。

卸载默认保留个人数据，方便以后重新安装。只有主动勾选“同时永久删除全部个人数据”并再次确认，才会删除订阅、文章、阅读进度、札记、Cookie 和本机配置。

## 完整性校验

`SHA256SUMS.txt` 包含完整离线安装程序的 SHA-256，可用于确认下载文件没有损坏。
