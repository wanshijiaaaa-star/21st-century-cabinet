# 21世纪内阁 · 本机使用说明

## 每次使用

安装版只需从桌面或开始菜单打开“21世纪内阁”。主站和公众号采集器会在后台静默启动，不需要打开或保留任何终端窗口。

首次启动会出现图形密码窗口，用于设置本机公众号采集器的管理员密码；用户名固定为 `admin`。

- 21世纪内阁：`http://127.0.0.1:4173/`
- 公众号采集器：`http://127.0.0.1:8001/`

关闭浏览器不会删除数据。再次打开“21世纪内阁”时，已经运行的服务会被复用，不会重复启动。

## 添加公众号

1. 准备目标公众号任意一篇公开文章链接。
2. 打开 `http://127.0.0.1:8001/add-subscription`，通过文章链接添加订阅。
3. 回到“21世纪内阁 → 信息源 → 从采集器选择”。
4. “勾选未接入”可一次选中全部尚未接入的公众号。
5. 接入后在信息源卡片中修改等级、类型、Inbox 和同步状态。

“添加来源”中的 Feed URL 必须是采集器生成的地址，例如：

```text
http://127.0.0.1:8001/feed/MP_WXS_数字.rss
```

不能填写普通 `mp.weixin.qq.com/s/...` 文章链接。

为降低触发平台限制的概率，建议分批添加公众号。微信读书授权失效时，在采集器“授权管理”中重新扫码。

## 奏章呈送与批红定案

- “奏章呈送”显示全部未读文章，越新的文章越靠上；同日按 A、B、C 级排序。
- 每篇文章左侧是批红勾选框。第一次点击加入“批红定案”，再次点击取消。
- 来源 Inbox 开关提供默认规则；单篇勾选可以覆盖来源默认规则。
- “奏章呈送 → 全部已读”会处理全部未读文章。
- “批红定案 → 一键调阅”会在后台准备当前全部批红文章，最多并行处理两篇。

## 正文阅读与札记

- 未缓存文章第一次点击只在后台调阅，不弹出阅读器。
- 状态变成“可阅读”后再次点击即可在站内打开。
- 调阅失败时显示“跳转原文”，点击后打开微信公众号原文。
- 正文图片会预留版面并淡入，避免把正在阅读的文字突然向下顶开。
- 阅读位置自动保存；约读到 95% 时自动标为已读。
- 在正文中选择文字并右键，可以划线或写笔记。
- 单击已有划线可以编辑笔记或删除批注。
- 左侧“札记”按文章归拢批注；收藏文章也会显示札记数量和最近摘录。

## 数据与同步

- 安装版个人数据：`%LOCALAPPDATA%\CenturyCabinet\Data\`
- 主数据库：`%LOCALAPPDATA%\CenturyCabinet\Data\site\cabinet.db`
- 自动备份：`%LOCALAPPDATA%\CenturyCabinet\Data\site\backups\`
- 采集器数据：`%LOCALAPPDATA%\CenturyCabinet\Data\collector-root\data\`
- 普通文章保留 90 天；收藏、含札记、未读完或时间未知的文章长期保留。
- A 级来源每 12 小时、B 级每天、C 级每 3 天检查。
- 单击“同步全部”可以立即检查全部已启用来源。
- 页面保存文章文字、索引、阅读状态和札记，不主动归档封面图片。

## 备份与恢复

在“设置 → 数据保管”单击“导出本机备份”。备份是 SQLite 文件，可以复制到移动硬盘或网盘。

恢复备份前先退出正在运行的本机服务。不要手工编辑正在使用的数据库。

## 源码模式的项目位置

以下目录结构只适用于开发者从源码运行。安装版用户无需管理这些目录：

```text
21世纪内阁/
├─ site/
└─ we-mp-rss/
```

可以整体移动 `21世纪内阁` 文件夹，但不要只移动其中一个子目录。
