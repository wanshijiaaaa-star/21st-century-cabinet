# Changelog

## v1.0.1 — 2026-10-05

### Added

- Windows 图形化离线安装程序、独立卸载程序和统一应用启动器。
- 应用私有 Python 运行时，普通用户无需安装开发环境或使用命令行。
- 桌面、开始菜单和 Windows“已安装的应用”入口。

### Changed

- 安装版程序与个人数据分离；覆盖安装保留数据，卸载默认保留数据。
- 主站和公众号采集器由同一入口在后台静默启动。
- 普通用户发行负载排除开发命令脚本与本机运行数据。

## v1.0 — 2026-10-03

### Added

- 本机优先的“21世纪内阁”信息阅读界面。
- 奏章呈送、批红定案、继续阅读、收藏、札记、类型和等级视图。
- 来源等级、类型、同步状态和默认批红控制。
- 从本机公众号采集器选择未接入公众号。
- A/B/C 分级低频同步、并发 Feed 读取、去重和错误隔离。
- 微信公众号正文按需调阅、本机缓存、图片代理和原文回退。
- 阅读进度、位置恢复、自动已读、划线和笔记。
- SQLite 自动备份、手动导出和文章保留策略。
- 卷轴启动页、主题切换、响应式侧栏和阅读字号设置。

### Changed

- 产品名称由计划阶段的 Personal Information Radar 调整为“21世纪内阁”。
- “注意力 Inbox”改名为“批红定案”，“Today”改为“奏章呈送”。
- 奏章呈送的实际语义调整为全部未读，并按日期及 A/B/C 等级排序。
- 来源不再使用二级标签；文章保留标签数据。
- 批红规则从仅来源级扩展为来源默认规则加单篇人工覆盖。
- 摘要控制为短文本、避免复制标题，并统一以句号结尾。
- 文章时间使用真实发布时间；无法取得时明确显示“时间未知”。

### Fixed

- 修复来源编辑入口、侧栏收起和多项无响应按钮。
- 修复封面代理与重复加载体验。
- 修复正文调阅完成或失败后自动弹出并打断当前阅读的问题。
- 修复正文图片载入造成的版面跳动。
- 修复批红一键调阅漏掉单篇人工选择的问题。
- 修复增强脚本覆盖文章卡片后勾选框不显示的问题。
- 修复采集器文章发布时间丢失、标题被错误用作摘要等元数据问题。
- 修复普通本机采集误触发级联协程警告的问题。

本记录依据当前 Git 历史与实际代码整理，不代表未留存的逐日开发日志。
